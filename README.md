### 1. 적금 상품 목록 연동하기

---

서버에서 적금 상품 목록을 불러와서 출력해주세요.

- [x] HTTP client는 "_손쉬운 API 사용을 위해 HTTP client 구현체를 미리 제공하고 있어요. `tosslib` 패키지에서 아래와 같이 import 해서 사용할 수 있어요._"를 참고해주세요.
- [x] 적금 상품 목록 API는 상품 목록 가져오기 (`GET /api/savings-products`) 를 참고해주세요.
- [x] 원단위를 표시할 때 콤마(,) 출력에 유의해주세요.

### 2. 저축 목표 입력 기능 만들기

---

목표 금액, 월 납입액, 저축 기간을 사용자가 입력할 수 있는 기능을 구현해주세요. <br/>
입력한 조건에 맞춰서 하단 적금 상품 목록에 보이는 상품 목록(`ProductList`)을 조건에 맞게 필터링해서 출력해주세요.

- [ ] input 입력값 유효성 검사 + (필요하다면) 간단한 테스트
- [ ] input 렌더링 최소환
- [ ] input 입력 디바운싱 적용 (선택)

**필터링 조건**

- [x] 월 납입액
  - `product.minMonthlyAmount` (최소 월 납입액)보다 크고
  - `product.maxMonthlyAmount` (최대 월 납입액)보다 작아야 함
- [x] 저축 기간
  - `product.availableTerms` (저축 기간)와 동일해야 함

### 3. 적금 상품 목록에서 선택 기능 만들기

---

- [x] 적금 상품 목록에서 적금 상품을 선택하면 오른쪽에 선택 아이콘을 표시해주세요.
- [x] 적금은 하나만 선택할 수 있어요.
- [x] 선택한 적금 상품의 정보는 이후 구현 중 “계산 결과” 탭에서 사용할 예정이에요.

### 4. 계산 결과 탭 만들기

---

"계산 결과" 탭을 클릭하면 `CalculationResult` 컴포넌트가 보이게 `SavingsCalculatorPage` 를 수정해주세요. 그리고 아래 기능들을 구현해주세요.

**계산 결과**

적금 상품 목록에서 사용자가 선택한 적금 상품에 대해 아래 공식에 맞게 금액을 계산해주세요.

- [x] 예상 수익 금액
  - 공식: `최종 금액 = 월 납입액 * 저축 기간 * (1 + 연이자율 * 0.5)`
- [x] 목표 금액과의 차이
  - 공식: `목표 금액과의 차이 = 목표 금액 - 예상 수익 금액`
- [x] 추천 월 납입 금액
  - 공식: `월 납입액 = 목표 금액 ÷ (저축 기간 * (1 + 연이자율 * 0.5))`
  - 1,000원 단위로 반올림
- [x] 만약 사용자가 적금 상품을 선택하지 않았다면 “상품을 선택해주세요”를 출력해주세요.

**추천 상품 목록**

- [ ] 사용자가 입력한 조건에 맞는 적금 상품 중 연 이자율이 가장 높은 2개의 상품을 출력해주세요.
- [ ] 만약 사용자가 선택한 상품이 있다면 적금 상품 목록과 마찬가지로 선택 아이콘을 표기해주세요.

## 고민되는 점

- context 값을 어느 깊이까지 호출해도 괜찮을까, 하는 고민이 됩니다. Context를 너무 깊은 컴포넌트 트리까지 전달하게 되면,
  - 어떤 컴포넌트가 어떤 Context 값을 읽고 있는지 추적하기가 어려워지고
  - 디버깅할 때 “어디서 값이 변경되었는지” 파악하기가 점점 복잡해질 수 있습니다.

- 컴포넌트를 만들다 보니, `<Spacing size={8} />` 이 친구가 계속 신경이 쓰이더라구요.
  - 저는 `SectionPadding` 이라는 컴포넌트를 만들어서 유동적으로 조절할 수 있게 구성했는데, 다른 분들은 어떻게 구성하셨는지 궁금합니다~
  - `Border`를 앞뒤로 padding으로 감싸는 컴포넌트를 만들어봐도 괜찮을 것 같기도 하구용..
